What is being measured? Formulas & interpretation

Variation across training sets

Train B independent datasets of size n. At each fixed test input x, compute f̄(x) = (1/B) Σ f̂ᵦ(x) and V(x) = (1/B) Σ (f̂ᵦ(x) − f̄(x))².

Average (f̄ − f)² and V across the same test inputs. The finite-ensemble identity is Eensemble, new noise[MSE] = bias² + variance + σ². Bias² is a Monte Carlo estimate of the procedure’s squared bias; it has finite-B error. The variance uses denominator B to preserve this identity.

The band is ±1 predictor standard deviation, not a confidence interval for the average and not a prediction interval. No normality of fitted predictions is assumed.

Variation across test sets

Freeze predictor #1. Generate B independent test sets of size m, without refitting. Their MSE variance estimates the variability of an evaluation of that fixed predictor.

For individual squared losses zᵢ, estimated SE(MSE) = sz/√m, using the sample loss variance with denominator m − 1. The displayed approximate 95% interval is MSE ± 1.96 SE, truncated at zero. This normal approximation can be poor for small test sets or heavy-tailed losses.

The reference risk and SE use numerical integration of the known simulated population. They do not include training-set variability. Independent IID test losses are essential; these intervals do not apply directly to overlapping CV folds.

Protect the test set: this is a teaching simulation. If you choose a degree using the error curve, you are using those data for validation. Real final assessment needs an untouched test set.

Polynomial fitting uses Householder QR and a Legendre basis on the known input interval (the same unregularized polynomial model, with better numerical conditioning). No test labels enter training. Very high degree and small training sets can produce extreme predictions; locked axes clip the drawing only. Use Fit axes to inspect them.
